# Docker Container Lifecycle

* `docker ps`: Lists all currently running containers along with their container IDs, status, and port mappings.
* `docker stop my-nginx`: Gracefully terminates the running Nginx container process.
* `docker ps`: Used to confirm that the stopped container is no longer active in the list of running containers.
* `docker rm my-nginx`: Permanently removes the stopped container instance and its writable container layer from the host system.
