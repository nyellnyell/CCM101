# Amazon Web Services (AWS) Research

## Brief Overview
Amazon Web Services (AWS) is a comprehensive and broadly adopted cloud platform provided by Amazon. Launched publicly in 2006, AWS offers over 200 fully featured services from data centers globally, spanning infrastructure as a service (IaaS), platform as a service (PaaS), and software as a service (SaaS).

## Global Infrastructure
AWS operates a global infrastructure consisting of **AWS Regions** and **Availability Zones (AZs)**.
* **Regions:** Geographic areas around the world that contain multiple isolated, physically separate Availability Zones.
* **Availability Zones:** Discrete data centers with independent power, cooling, and physical security, connected through low-latency, high-throughput network links.
* **Edge Locations:** A global network of Point of Presence (PoP) locations used for content delivery (Amazon CloudFront) to reduce latency for end users.

## Cloud Management Console
The AWS Management Console is a web-based interface that allows users to manage and access AWS resources, monitor service usage, track billing, and configure security permissions.

## Four (4) Core Services
1. **Amazon EC2 (Elastic Compute Cloud):** Provides resizable compute capacity in the cloud as virtual servers.
2. **Amazon S3 (Simple Storage Service):** An object storage service offering high scalability, data availability, security, and performance.
3. **Amazon RDS (Relational Database Service):** A managed service that simplifies setting up, operating, and scaling relational databases (e.g., MySQL, PostgreSQL, Oracle).
4. **Amazon VPC (Virtual Private Cloud):** Allows users to provision a logically isolated section of the AWS Cloud where they can launch AWS resources in a virtual network.

## Three (3) Advantages
1. **Market Leadership & Ecosystem:** AWS has the largest market share and the most mature ecosystem of tools, third-party integrations, and community support.
2. **Broad & Deep Service Portfolio:** Offers the largest breadth of services, ranging from core compute to advanced AI/ML, serverless, and IoT platforms.
3. **High Reliability & Scalability:** Designed for high availability with robust multi-AZ architectures and automatic scaling capabilities.

## Typical Enterprise Use Cases
* Host scalable web applications and e-commerce platforms.
* Big data processing and real-time analytics pipelines.
* Enterprise data backup, disaster recovery, and long-term archiving.
