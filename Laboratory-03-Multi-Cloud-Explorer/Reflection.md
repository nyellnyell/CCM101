
# Checkpoint 8 – Mission Reflection

## Reflection Essay

Among the three major cloud providers evaluated, Amazon Web Services (AWS) impressed me the most due to its sheer scale, maturity, and well-structured service offerings. AWS has established a robust ecosystem that sets the standard for cloud computing. Its extensive collection of tools, clear documentation, and flexible pay-as-you-go scaling models make it an exceptionally powerful ecosystem for both high-growth startups and massive enterprise operations.

Despite their market competition, AWS, Azure, and Google Cloud Platform (GCP) share fundamental structural similarities. All three providers build their operations around global infrastructure divided into Regions and isolated Availability Zones to ensure high availability and redundancy. Furthermore, they offer equivalent core building blocks—such as virtual compute instances, object storage buckets, relational databases, identity access management, and managed Kubernetes platforms—allowing skills learned on one platform to transfer easily to the others.

Through analyzing various client scenarios, it became evident that technical features alone do not dictate cloud selection; business requirements are the primary driver. Factors such as existing technology stacks, budget constraints, technical specialization, and compliance standards shape the decision-making process. For example, an organization deeply reliant on Microsoft Active Directory naturally leans toward Azure, whereas an AI research startup prioritizes GCP’s advanced machine learning pipelines.

Acting as a Cloud Solutions Consultant provided invaluable insight into approaching technical problems from an architectural perspective. Rather than choosing tools arbitrarily, I learned to assess organizations holistically by evaluating their financial, infrastructure, and scalability needs. 

Ultimately, completing this mission has significantly elevated my GitHub Cloud Computing Portfolio. Beyond simply storing code, my portfolio now demonstrates hands-on experience in cloud platform comparison, system auditing via Linux commands, and strategic decision-making. Structuring these deliverables cleanly using Markdown and Git version control highlights both technical competence and professional documentation skills for potential employers.
