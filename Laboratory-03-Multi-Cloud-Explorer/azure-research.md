# Microsoft Azure Research

## Brief Overview
Microsoft Azure is a cloud computing service created by Microsoft for building, testing, deploying, and managing applications and services through Microsoft-managed data centers. Launched in 2010, Azure integrates deeply with existing Microsoft enterprise software and hybrid cloud environments.

## Global Infrastructure
Microsoft Azure features a widespread global footprint organized into **Regions**, **Availability Zones**, and **Geographies**.
* **Regions:** Sets of data centers deployed within a latency-defined perimeter and connected through a dedicated regional low-latency network.
* **Availability Zones:** Unique physical locations within an Azure region, each equipped with independent power, cooling, and networking.
* **Geographies:** Discrete markets, typically containing two or more regions, that preserve data residency and compliance boundaries.

## Cloud Management Console
The Azure Portal is a unified web-based console that serves as an alternative to command-line tools. It enables users to build, manage, and monitor everything from simple web apps to complex cloud deployments.

## Four (4) Core Services
1. **Azure Virtual Machines (VMs):** On-demand, scalable computing resources offering IaaS for Windows and Linux instances.
2. **Azure Blob Storage:** Massively scalable object storage for unstructured data such as text, images, videos, and backups.
3. **Azure SQL Database:** A fully managed relational database engine (PaaS) based on the latest enterprise edition of Microsoft SQL Server.
4. **Azure Virtual Network (VNet):** Enables Azure resources to securely communicate with each other, the internet, and on-premises networks.

## Three (3) Advantages
1. **Seamless Microsoft Integration:** Unmatched compatibility with existing Microsoft stack software (Windows Server, Active Directory, Office 365, SQL Server).
2. **Strong Hybrid Cloud Capabilities:** Tools like Azure Arc and Azure Stack allow seamless management of hybrid and multi-cloud environments.
3. **Enterprise Compliance & Security:** Holds a wide variety of compliance certifications suitable for healthcare, finance, and government sectors.

## Typical Enterprise Use Cases
* Enterprise hybrid cloud deployments extending on-premises Active Directory and Windows Server infrastructure.
* Enterprise resource planning (ERP) systems and Active Directory domain services hosting.
* App modernization using Azure App Service and containerized microservices.
